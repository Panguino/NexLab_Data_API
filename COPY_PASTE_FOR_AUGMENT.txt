---

🌍 REAL-TIME HAZARDS DATA:

Endpoint: GET /api/hazards
Updated: Every 30 seconds
Use for: Current active weather alerts and hazards

Query Parameters:
- region: CONUS, ALASKA, HAWAII
- state: 2-letter state code (FL, CA, TX, etc.)
- hazardType: TORNADO, SEVERE, FIRE, WINTER, MARINE, FLOOD, WIND, HEAT, COLD, FROST, FREEZE
- hazardLevel: WARNING, WATCH, ADVISORY, STATEMENT

Examples:
- Get all hazards: /api/hazards
- Get tornado warnings: /api/hazards?hazardType=TORNADO&hazardLevel=WARNING
- Get Florida hazards: /api/hazards/state/FL
- Get county hazards: /api/hazards/county/12086
- Get region hazards: /api/hazards/region/CONUS

---

📊 HISTORICAL ALERTS DATA:

Endpoints:
1. GET /api/alerts/history/optimized?date=YYYY-MM-DD
   - Get deduplicated alerts for specific date with timeline
   - Parameters: date (required), region (optional)
   - Example: /api/alerts/history/optimized?date=2025-10-23

2. GET /api/alerts/history/last?hours=N
   - Get alerts from last N hours (max 720 hours = 30 days)
   - Parameters: hours (optional, default 24), region (optional)
   - Examples: /api/alerts/history/last?hours=24 or /api/alerts/history/last?hours=168

Storage: Amazon S3 with 28-day retention
Use for: Historical alert data and timeline tracking

---

📋 ALERT DATA STRUCTURE:

Each alert contains:
- id: Unique alert identifier
- event: Type of weather event (e.g., "Tornado Warning")
- headline: Short headline
- description: Detailed description
- severity: Extreme, Severe, Moderate, Minor
- urgency: Immediate, Expected, Future, Past
- certainty: Observed, Likely, Possible
- areaDesc: Description of affected area
- sent, effective, onset, expires, ends: ISO 8601 UTC timestamps
- locations: Array of affected locations with:
  - id: composite key (county-FIPS, coast-ID, offshore-ID)
  - locationId: FIPS code or location ID
  - name: location name
  - type: county, coast, or offshore
  - state: state code (if applicable)
  - lat, lon: coordinates
