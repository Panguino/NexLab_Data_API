🌍 REAL-TIME HAZARDS ENDPOINTS
────────────────────────────────────────────────────────────────────────────────

1. GET /api/hazards
   Get all active hazards with optional filters
   
   Query Parameters:
   - region: CONUS, ALASKA, HAWAII
   - state: 2-letter state code (FL, CA, TX, etc.)
   - hazardType: TORNADO, SEVERE, FIRE, WINTER, MARINE, FLOOD, WIND, HEAT, COLD, FROST, FREEZE
   - hazardLevel: WARNING, WATCH, ADVISORY, STATEMENT
   
   Examples:
   /api/hazards
   /api/hazards?region=CONUS&hazardType=TORNADO
   /api/hazards?state=FL&hazardLevel=WARNING

2. GET /api/hazards/county/:fips
   Get hazards for specific county by FIPS code
   
   Example:
   /api/hazards/county/12086

3. GET /api/hazards/state/:state
   Get hazards for specific state
   
   Example:
   /api/hazards/state/FL

4. GET /api/hazards/region/:region
   Get hazards for specific region
   
   Example:
   /api/hazards/region/CONUS


📊 HISTORICAL ALERTS ENDPOINTS
────────────────────────────────────────────────────────────────────────────────

1. GET /api/alerts/history/optimized?date=YYYY-MM-DD
   Get deduplicated alerts for specific date with timeline
   
   Query Parameters:
   - date (required): YYYY-MM-DD format
   - region (optional): CONUS, ALASKA, HAWAII
   
   Examples:
   /api/alerts/history/optimized?date=2025-10-23
   /api/alerts/history/optimized?date=2025-10-23&region=CONUS

2. GET /api/alerts/history/last?hours=N
   Get alerts from last N hours (max 720 hours = 30 days)
   
   Query Parameters:
   - hours (optional): 1-720, default 24
   - region (optional): CONUS, ALASKA, HAWAII
   
   Examples:
   /api/alerts/history/last?hours=24
   /api/alerts/history/last?hours=168
   /api/alerts/history/last?hours=24&region=CONUS

📋 ALERT DATA FIELDS
────────────────────────────────────────────────────────────────────────────────

id                - Unique alert identifier
event             - Type of weather event (e.g., "Tornado Warning")
headline          - Short headline
description       - Detailed description
severity          - Extreme, Severe, Moderate, Minor
urgency           - Immediate, Expected, Future, Past
certainty         - Observed, Likely, Possible
areaDesc          - Description of affected area
sent              - When alert was sent (ISO 8601 UTC)
effective         - When alert becomes effective (ISO 8601 UTC)
onset             - When weather event begins (ISO 8601 UTC)
expires           - When alert expires (ISO 8601 UTC)
ends              - When weather event ends (ISO 8601 UTC)
locations         - Array of affected locations with:
                    - id: composite key (county-FIPS, coast-ID, offshore-ID)
                    - locationId: FIPS code or location ID
                    - name: location name
                    - type: county, coast, or offshore
                    - state: state code (if applicable)
                    - lat: latitude
                    - lon: longitude
